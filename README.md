## 运行与目录

下载整个项目，用 **Google Chrome** 打开 `index.html`，无需安装框架、启动服务器或联网加载资源。

首页默认展示进行中信息，可切换寻物/招领，再按类别或地点筛选。点击搜索入口，输入名称、类别、地点或描述关键词；多个关键词用空格分隔，需要全部匹配。回车和搜索按钮都可提交，常用词按钮可快速检索。默认排除已结束信息，勾选“包括已结束的信息”后查看历史状态。“清空条件”恢复默认查询。筛选条件保存在地址片段中，刷新后可恢复。

点击任意信息卡片进入详情，核对时间、地点和特征，再点击“查看联系方式”。复制成功时提示已复制；浏览器限制自动复制时会选中联系方式，并提示使用快捷键手动复制。“返回列表”保留进入详情前的筛选条件，详情地址也可刷新或直接打开。信息不存在时给出返回入口。

## 与发布模块的数据约定

所有功能共用 `CampusPosts.STORAGE_KEY`，其值为 `campus-lost-found.posts.v1`。对应的 `localStorage` 值是 **JSON 数组**，一条信息的格式如下：

```json
{
  "id": "post-001",
  "type": "lost",
  "name": "黑色长柄雨伞",
  "category": "雨伞",
  "place": "图书馆一楼",
  "time": "2026-10-07T08:10",
  "createdAt": "2026-10-07T09:00:00+08:00",
  "status": "寻找中",
  "desc": "伞柄有银色金属环。",
  "contact": "微信：example",
  "ownerId": "发布者标识"
}
```

- `id` 是非空字符串或有限数值，在整个数组内唯一；其他模块可以添加所有者等字段。
- `type` 为 `lost`（寻物）或 `found`（招领）。
- 寻物状态为 `寻找中` / `已找到`；招领状态为 `招领中` / `已归还`。
- `time` 是丢失/拾取时间；`createdAt` 是发布时间。首页按发布时间降序排列；兼容缺少 `createdAt` 的原型数据，此时按 `time` 排序。带时区的 ISO 时间在界面上转换为北京时间，不带时区的表单时间按原值显示。
- `name`、`category`、`place`、`time`、`desc` 为字符串。`contact` 可为空，此时详情应提示未提供联系方式。
- 写入或更新成功后，在同一窗口派发 `window.dispatchEvent(new Event('campus:posts-changed'))`，列表会重新读取。其他窗口的存储变化通过 `storage` 事件更新。
- 本模块只读取数据，不覆盖存储。首次没有数据时显示演示信息；保存的空数组代表确实没有信息，不能重新补入演示数据。
- 读取失败或数据损坏时显示明确提示并使用演示信息，保留原始存储供排查。

直接打开 HTML 时，存储与浏览器配置、文件路径有关。联调时保持同一个 `index.html` 入口，在 Chrome 中验证刷新后的数据。发布模块必须处理存储失败，不能把保存失败提示成发布成功。

## 测试

开发环境使用 Node.js 内置的 `node:test` 和 `node:assert/strict`，无需安装测试依赖；本次验证环境为 Node.js 24.16.0。Node.js 仅用于开发测试，运行网页不需要它。[官方测试工具文档](https://nodejs.org/api/test.html)

```powershell
node --test tests/posts.test.cjs
```

测试直接调用正式程序的查询和读取函数，按条件分支构造正常、边界及错误数据；使用内存中的模拟存储，避免影响浏览器现有内容。页面跳转、键盘操作和本地文件兼容性还需在 Chrome 走查。

本次 32 个自动化单元测试全部通过，覆盖以下分支：

| 模块 | 主要测试情况 |
| --- | --- |
| 首页与读取 | 有效状态、类型筛选、组合条件、排序、空列表；首次读取、本地空数组、损坏 JSON、重复 ID、存储访问失败 |
| 搜索 | 关键词命中/不命中、空白与大小写、多词匹配、组合筛选、历史信息开关、HTML 字符作为普通文本 |
| 详情与联系 | 数值/字符串 ID、缺少或删除的记录、空联系方式、带时区的发布时间、返回条件保留、剪贴板成功/不可用/权限拒绝 |

简易写法：每个用例先构造固定数据，再调用实际业务函数，最后用 `assert.equal` 或 `assert.deepEqual` 比较预期和实际结果。例如，给一条进行中的记录和一条已结束记录，断言首页结果只包含前者。存储和剪贴板使用可控制成功/失败的模拟对象，使错误分支也能稳定复现；修复后重新运行相关测试，防止原有行为退化。测试代码在 `tests/posts.test.cjs`。
